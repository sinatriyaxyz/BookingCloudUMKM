# Sesi 12 — Frontend pemilik: profil, layanan, jam

```
Halaman pemilik (di bawah /owner):
- Profil UMKM (form + tampilkan link halaman publik).
- Layanan: tabel + form tambah/ubah, hapus dengan konfirmasi.
- Jam operasional: 7 baris (hari, buka, tutup, centang libur) + daftar tanggal libur dengan tambah/hapus.
Gunakan komponen form/tabel yang dipakai ulang. Tidak perlu library UI besar.
Selesai bila: semua halaman terhubung ke API dan `npm run build` sukses.
```

Setelah selesai: pastikan tes lulus, centang sesi 12 di PROGRESS.md, git commit. Jangan lanjut ke sesi berikutnya.
